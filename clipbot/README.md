# Бот автоклипов Twitch в Телеграме

Бот сидит в чате выбранных каналов Twitch. Когда чат «взрывается» (пишут в разы чаще обычного, сыпят KEKW, «ахах», 😂),
он делает **клип встроенным инструментом Twitch** — как кнопка «Клип» в плеере, от имени вашего аккаунта — и присылает
ссылку вам в Телеграм:

```
🔥 5opka — чат ×4,2 (63 сообщ. за 15 с, «KEKW»)
Клип: https://clips.twitch.tv/…  · эфир 1:02:03
```

«эфир 1:02:03» — где этот момент в записи эфира. Клип длится ~30 секунд и заканчивается на моменте всплеска;
обрезать его можно на странице клипа на Twitch.

Работает только через официальный API Twitch: вы один раз входите в свой аккаунт Twitch из бота. Бот только **читает**
чат и ничего туда не пишет. Каналы вы добавляете сами — командами в боте.

## Что понадобится

1. **VPS** (сервер в интернете) с Ubuntu 22.04 или 24.04. Хватит самого маленького: 1 ядро, 1 ГБ памяти.
   Выбирайте сервер за пределами РФ — так Twitch и Телеграм не будут тормозить или блокироваться.
   После покупки у вас будут **IP-адрес** и **пароль root**.
2. **Ключи Twitch** — те же, что для приложения (Client ID и Client Secret с dev.twitch.tv/console).
   В приложении на dev.twitch.tv в поле **OAuth Redirect URLs** должен быть `http://localhost` — у вас он уже есть.
3. **Телеграм-бот**: в Телеграме откройте **@BotFather** → `/newbot` → придумайте имя и адрес (должен кончаться на `bot`)
   → BotFather пришлёт **токен** вида `123456789:AA…`. Никому его не пересылайте.

## Установка (10 минут, с телефона)

1. Поставьте на телефон приложение для SSH — например **Termius** (или Termux и команду `ssh`).
2. Подключитесь к серверу: адрес — IP сервера, пользователь — `root`, пароль — из письма хостинга.
3. Вставьте и выполните одну команду:

   ```bash
   curl -fsSL https://raw.githubusercontent.com/vseznamus/tiktok-clipper/main/clipbot/install.sh | sudo bash
   ```

4. Установщик поставит Docker и спросит по очереди: **токен бота**, **Twitch Client ID**, **Twitch Client Secret**
   (при вводе токена и секрета символы не видны — это нормально; вставьте и нажмите Enter).
   Ключи остаются только на сервере, в файле `/opt/tiktok-clipper/clipbot/.env`.
5. В конце появится строка вида `/start 48213907` — это **код привязки**.

## Первый запуск в Телеграме

1. Откройте своего бота и отправьте `/start 48213907` (ваш код). Теперь бот слушается только вас.
2. Бот пришлёт **ссылку входа в Twitch**. Откройте её в браузере → **«Разрешить»**
   (бот просит только «читать чат» и «создавать клипы»).
3. Браузер перейдёт на адрес `http://localhost/?code=…` и покажет ошибку — **так и должно быть**.
   Скопируйте этот адрес из адресной строки целиком и пришлите боту. Ответ: «✅ Вошёл в Twitch как …».
4. **«➕ Добавить канал»** → пришлите логин (`5opka`) или ссылку на канал. Или сразу: `/add 5opka`.

Готово: бот следит за чатом круглосуточно и сам перезапускается после перезагрузки сервера.

## Команды

| Команда | Что делает |
|---|---|
| `/add логин`, кнопка «➕ Добавить канал» | следить за каналом (логин из адреса twitch.tv/логин или ссылка) |
| `/del логин` | перестать следить |
| `/list`, кнопка «📋 Каналы» | каналы, сколько клипов сделано, сколько сообщений в минуту сейчас |
| `/threshold 3` | во сколько раз чат должен ускориться (1.5–10). Больше — реже и точнее, меньше — чаще |
| `/minmsgs 15` | минимум сообщений за 15 секунд (3–500): защита от «всплесков» в маленьких чатах |
| `/cooldown 3` | минимум минут между клипами одного канала (1–60) |
| `/pause`, `/resume` | приостановить и продолжить клипы |
| `/status`, кнопка «⚙️ Настройки» | вход в Twitch, чат, каналы, текущие настройки |
| `/login` | войти в Twitch заново (если бот попросит) |

**Как бот решает, что момент интересный.** Каждые 2 секунды он сравнивает последние 15 секунд чата с обычным темпом
этого эфира за 10 минут (реакции вроде KEKW, LUL, «ахах», «ору», 😂 весят в 1,6 раза больше). Если сообщений
в `threshold` раз больше обычного и не меньше `minmsgs` — клип. Первую минуту после запуска бот только привыкает к чату.

Подбор под канал: большой чат (тысячи зрителей) — `/minmsgs 60`, `/threshold 3`; маленький (до 200 зрителей) —
`/minmsgs 8`, `/threshold 4`. Слишком много клипов — поднимите `threshold` или `cooldown`.

## Обслуживание

Подключитесь к серверу по SSH и выполните нужное:

* обновить бота — та же команда установки (настройки, каналы и вход сохранятся);
* журнал работы:
  ```bash
  cd /opt/tiktok-clipper/clipbot && docker compose logs -f --tail 50
  ```
* поменять ключи — `nano /opt/tiktok-clipper/clipbot/.env`, затем:
  ```bash
  cd /opt/tiktok-clipper/clipbot && docker compose up -d
  ```
* остановить бота:
  ```bash
  cd /opt/tiktok-clipper/clipbot && docker compose down
  ```

Привязать бота к другому аккаунту Телеграма: удалите файл `/opt/tiktok-clipper/clipbot/data/state.json`
(сбросятся и каналы), перезапустите бота и снова `/start код`.

## Если что-то не так

| Сообщение / проблема | Что сделать |
|---|---|
| Бот не отвечает | Журнал (см. выше). Чаще всего опечатка в токене — поправьте `.env` и перезапустите |
| «Это личный бот…» | Отправьте `/start` и код привязки из установки (`grep PAIR /opt/tiktok-clipper/clipbot/.env`) |
| «Twitch не принял код» | Ссылка входа живёт несколько минут — `/login` и повторите. Проверьте Redirect URL `http://localhost` |
| «Вход в Twitch истёк — /login» | Вы сменили пароль Twitch или отозвали доступ — `/login` |
| «канал запретил клипы» | Стример выключил клипы или разрешил их только подписчикам/фолловерам — подпишитесь или уберите канал |
| «канал не в эфире» | Всплеск в чате оффлайн-канала — клип возможен только во время эфира |
| «Twitch просит подождать» | Слишком много клипов подряд — поднимите `/cooldown` |
| Клипов нет совсем | `/list`: если «чат сейчас: 0» при идущем эфире — `/status`, проверьте «Чат: подключён» |

## Честно об ограничениях

* Клипы создаются **от вашего аккаунта** и видны на странице клипов канала — стример видит, кто их сделал.
  Следите за каналами, которые не против клипов (а лучше — с программой нарезок), и не ставьте слишком низкий порог.
* Если у канала задержка эфира (stream delay), клип может начаться чуть раньше всплеска.
* Бот не скачивает видео — только присылает ссылку. Файлы клипов стример (и редакторы канала) скачивает в своей
  панели Twitch; если вы режете для стримера, попросите доступ у него.
