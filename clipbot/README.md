# Бот автоклипов Twitch в Телеграме

Бот сидит в чате выбранных каналов Twitch. Когда чат «взрывается» (пишут в разы чаще обычного, сыпят KEKW, «ахах», 😂),
через 30 секунд он делает **клип на минуту встроенным инструментом Twitch** — как кнопка «Клип» в плеере, от имени
вашего аккаунта — и присылает ссылку вам в Телеграм. В клип попадают 30 секунд до всплеска и 30 секунд после,
так что момент — посередине (длиннее 60 секунд Twitch клипы не делает):

```
🔥 5opka — чат ×4,2 (63 сообщ. от 41 чел. за 15 с, волна «kekw» ×18)
Клип (минута, момент посередине): https://clips.twitch.tv/…
Момент в эфире: 1:01:33
Запись эфира с начала клипа: https://www.twitch.tv/videos/…?t=1h1m3s
```

Под ссылкой на клип — **«✂️ Редактор клипа»**: там можно включить субтитры Twitch, подвинуть границы и сменить
название (ссылка действует 24 часа). Сам бот этот переключатель нажать не может — в официальном API его нет.

Нужно больше — команда `/clips 2`: тогда клипов два по минуте, **«минута до»** сразу и **«минута после»** через
минуту (ответом на первое сообщение) — вместе непрерывные 2 минуты, момент на стыке. Вернуть один клип — `/clips 1`.
Если эфир закончился раньше, бот так и напишет.

Работает только через официальный API Twitch: вы один раз входите в свой аккаунт Twitch из бота. Бот только **читает**
чат и ничего туда не пишет. Каналы вы добавляете сами — командами в боте.

## Что понадобится

1. Где будет работать бот — одно из двух:
   * **роутер Keenetic с Entware (OPKG)** — бесплатно, роутер и так включён круглосуточно (раздел «Установка на роутер»);
   * **VPS** (сервер в интернете) с Ubuntu 22.04 или 24.04. Хватит самого маленького: 1 ядро, 1 ГБ памяти.
     Выбирайте сервер за пределами РФ — так Twitch и Телеграм не будут тормозить или блокироваться.
     После покупки у вас будут **IP-адрес** и **пароль root**.
2. **Ключи Twitch** — те же, что для приложения (Client ID и Client Secret с dev.twitch.tv/console).
   В приложении на dev.twitch.tv в поле **OAuth Redirect URLs** должен быть `http://localhost` — у вас он уже есть.
3. **Телеграм-бот**: в Телеграме откройте **@BotFather** → `/newbot` → придумайте имя и адрес (должен кончаться на `bot`)
   → BotFather пришлёт **токен** вида `123456789:AA…`. Никому его не пересылайте.

## Установка на VPS (10 минут, с телефона)

1. Поставьте на телефон приложение для SSH — например **Termius** (или Termux и команду `ssh`).
2. Подключитесь к серверу: адрес — IP сервера, пользователь — `root`, пароль — из письма хостинга.
3. Вставьте и выполните одну команду:

   ```bash
   curl -fsSL https://raw.githubusercontent.com/vseznamus/tiktok-clipper/main/clipbot/install.sh | sudo bash
   ```

4. Установщик поставит Docker и спросит по очереди: **токен бота**, **Twitch Client ID**, **Twitch Client Secret**
   (при вводе токена и секрета символы не видны — это нормально; вставьте и нажмите Enter).
   Ключи остаются только на сервере, в файле `/opt/tiktok-clipper/clipbot/.env`.
5. В конце появится строка вида `/start 48213907` — это **код привязки**.

## Установка на роутер Keenetic

Подходит Keenetic с установленным **Entware** (компонент «Поддержка открытых пакетов» / OPKG). Нужно около 60 МБ места
(флешка в USB-разъёме роутера или встроенная память, если Entware стоит в ней) и желательно 256 МБ памяти у роутера —
бот занимает около 30 МБ. Если Entware ещё нет — поставьте его по официальной инструкции Keenetic
(help.keenetic.com, «Установка системы пакетов репозитория Entware»).

1. Подключитесь по SSH к **Entware** (не к командной строке самого роутера): адрес — IP роутера (обычно `192.168.1.1`),
   **порт 222**, пользователь `root`, пароль — ваш (по умолчанию у Entware `keenetic`; смените его командой `passwd`).
2. Выполните по очереди:

   ```bash
   opkg update && opkg install curl ca-bundle
   ```

   ```bash
   curl -fsSL https://raw.githubusercontent.com/vseznamus/tiktok-clipper/main/clipbot/install-keenetic.sh | sh
   ```

3. Установщик поставит Python (несколько минут) и спросит **токен бота**, **Twitch Client ID**, **Twitch Client Secret**
   (символы токена и секрета не видны — это нормально). Ключи остаются только на роутере, в `/opt/clipbot/.env`.
4. В конце — строка `/start 12345678` с **кодом привязки**. Бот сам запускается при включении роутера и сам
   поднимается, если упал или пропадал интернет.

Обслуживание на роутере (в SSH Entware):

* обновить — та же команда установки (ключи, каналы и вход сохранятся);
* журнал — `tail -f /opt/clipbot/bot.log`;
* перезапуск — `/opt/etc/init.d/S99clipbot restart` (а также `stop`, `start`, `status`);
* поменять ключи — `opkg install nano`, затем `nano /opt/clipbot/.env` и перезапуск;
* удалить — `/opt/etc/init.d/S99clipbot stop; rm -rf /opt/clipbot /opt/etc/init.d/S99clipbot`.

## Первый запуск в Телеграме

1. Откройте своего бота и отправьте `/start 48213907` (ваш код). Теперь бот слушается только вас.
2. Бот пришлёт **ссылку входа в Twitch**. Откройте её в браузере → **«Разрешить»**
   (бот просит только «читать чат» и «создавать клипы»).
3. Браузер перейдёт на адрес `http://localhost/?code=…` и покажет ошибку — **так и должно быть**.
   Скопируйте этот адрес из адресной строки целиком и пришлите боту. Ответ: «✅ Вошёл в Twitch как …».
4. **«➕ Добавить канал»** → пришлите логин (`5opka`) или ссылку на канал. Или сразу: `/add 5opka`.

Готово: бот следит за чатом круглосуточно и сам перезапускается после перезагрузки сервера.

## Команды

| Команда | Что делает |
|---|---|
| `/add логин`, кнопка «➕ Добавить канал» | следить за каналом (логин из адреса twitch.tv/логин или ссылка) |
| `/del логин` | перестать следить |
| `/list`, кнопка «📋 Каналы» | каналы, сколько клипов сделано, оценки 👍/👎, порог канала, сколько сообщений в минуту сейчас |
| `/threshold 3` | во сколько раз чат должен ускориться (1.5–10). Больше — реже и точнее, меньше — чаще |
| `/minmsgs 15` | минимум сообщений за 15 секунд (3–500): защита от «всплесков» в маленьких чатах |
| `/clips 1` или `/clips 2` | 1 — один клип на минуту, момент посередине (по умолчанию); 2 — два клипа: минута до и минута после |
| `/vclips 2` | писать, когда за 2 минуты клипнули столько разных зрителей (1–5; 0 — не следить) |
| `/cooldown 3` | минимум минут между моментами одного канала (2–60): на каждый момент уходит 2 минуты эфира |
| `/pause`, `/resume` | приостановить и продолжить клипы |
| `/status`, кнопка «⚙️ Настройки» | вход в Twitch, чат, каналы, текущие настройки |
| `/login` | войти в Twitch заново (если бот попросит) |

**Как бот решает, что момент интересный.** Сигналы работают вместе:

1. **Чат: сообщения и люди.** Каждые 2 секунды бот сравнивает последние 15 секунд чата с обычным темпом этого эфира
   за 10 минут — и по числу сообщений, и по числу **разных авторов**. Всплеск — когда в `threshold` раз выросло и то,
   и другое: один спамер или чат-бот (Nightbot, StreamElements…) клипа не вызовет. Реакции вроде KEKW, LUL, «ахах»,
   «ору», 😂 весят в 1,6 раза больше; сообщений должно быть не меньше `minmsgs`.
2. **Волна.** Если одно и то же («KEKW», «F», копипасту) пишут сразу многие — это подкрепляет всплеск, а в сообщении
   видно: `чат ×4,2 (63 сообщ. от 41 чел. за 15 с, волна «kekw» ×18)`.
3. **Клипы зрителей.** Раз в 45 секунд бот смотрит (официальный API) новые клипы каналов, которые сейчас в эфире.
   Если за 2 минуты клипнули `vclips` разных зрителей (по умолчанию 2): момент уже прислан по чату — бот ответит на то
   сообщение «🎬 Зрители тоже клипнули этот момент» со ссылками; не прислан — напишет отдельно «🎬 зрители клипают»
   с самыми просматриваемыми клипами и ссылкой на запись эфира. Клипы самого бота не считаются.
4. **Ваши оценки 👍 / 👎** под каждым клипом. 👎 «Мимо» — порог этого канала поднимается (клипов меньше, но точнее),
   👍 «Хороший» — немного опускается. Поправка у каждого канала своя (от ×0,7 до ×2 к общему порогу), её видно в `/list`.

Первую минуту после запуска бот только привыкает к чату.

Подбор под канал: большой чат (тысячи зрителей) — `/minmsgs 60`, `/threshold 3`; маленький (до 200 зрителей) —
`/minmsgs 8`, `/threshold 4`. Слишком много клипов — поднимите `threshold` или `cooldown`.

## Обслуживание на VPS

Подключитесь к серверу по SSH и выполните нужное:

* обновить бота — та же команда установки (настройки, каналы и вход сохранятся);
* журнал работы:
  ```bash
  cd /opt/tiktok-clipper/clipbot && docker compose logs -f --tail 50
  ```
* поменять ключи — `nano /opt/tiktok-clipper/clipbot/.env`, затем:
  ```bash
  cd /opt/tiktok-clipper/clipbot && docker compose up -d
  ```
* остановить бота:
  ```bash
  cd /opt/tiktok-clipper/clipbot && docker compose down
  ```

Привязать бота к другому аккаунту Телеграма: удалите файл `state.json` (VPS — `/opt/tiktok-clipper/clipbot/data/`,
роутер — `/opt/clipbot/data/`; сбросятся и каналы), перезапустите бота и снова `/start код`.

## Если что-то не так

| Сообщение / проблема | Что сделать |
|---|---|
| Бот не отвечает | Журнал (см. выше). Чаще всего опечатка в токене — поправьте `.env` и перезапустите |
| «Это личный бот…» | Отправьте `/start` и код привязки из установки (VPS: `grep PAIR /opt/tiktok-clipper/clipbot/.env`, роутер: `grep PAIR /opt/clipbot/.env`) |
| «Twitch не принял код» | Ссылка входа живёт несколько минут — `/login` и повторите. Проверьте Redirect URL `http://localhost` |
| «Вход в Twitch истёк — /login» | Вы сменили пароль Twitch или отозвали доступ — `/login` |
| «канал запретил клипы» | Стример выключил клипы или разрешил их только подписчикам/фолловерам — подпишитесь или уберите канал |
| «канал не в эфире» | Всплеск в чате оффлайн-канала — клип возможен только во время эфира |
| «Twitch просит подождать» | Слишком много клипов подряд — поднимите `/cooldown` |
| Роутер: «Не найден Entware» | Вы зашли в командную строку роутера, а не в Entware — подключитесь на порт 222 |
| Роутер: бот не отвечает после перезагрузки | Флешка с Entware не подключилась — проверьте её, затем `/opt/etc/init.d/S99clipbot start` |
| Клипов нет совсем | `/list`: если «чат сейчас: 0» при идущем эфире — `/status`, проверьте «Чат: подключён» |

## Честно об ограничениях

* Клипы создаются **от вашего аккаунта** и видны на странице клипов канала — стример видит, кто их сделал.
  Следите за каналами, которые не против клипов (а лучше — с программой нарезок), и не ставьте слишком низкий порог.
* Если у канала задержка эфира (stream delay), клип может начаться чуть раньше всплеска.
* Бот не скачивает видео — только присылает ссылку. Файлы клипов стример (и редакторы канала) скачивает в своей
  панели Twitch; если вы режете для стримера, попросите доступ у него.
