# Приложение «Нарезка» (APK): инструкция

Это та же программа, что и веб-версия, но в виде обычного приложения для Android 8 и новее.
**Termux не нужен**, сервер запускать не надо: открыли значок — работаете. Видео собирается
аппаратным кодировщиком телефона — это намного быстрее, чем в Termux.

Экраны и кнопки те же, что описаны в INSTRUCTION.md (части B и C). Ниже — только то, что в приложении
отличается.

## 1. Установка

1. Соберите APK (см. `android/BUILD_APK.md`) или возьмите готовый файл `app-release.apk`.
2. Откройте файл на телефоне. Android спросит: «Разрешить установку приложений из этого источника?» —
   нажмите **Настройки** → включите переключатель → назад → **Установить**.
3. Появится значок **«Нарезка»**. Откройте его.
4. На вопрос про уведомления нажмите **Разрешить** — в уведомлении виден прогресс нарезки,
   и благодаря ему Android не закрывает приложение, пока идёт работа.

## 2. Первая настройка

1. **Модель распознавания речи (для субтитров).** Вкладка **«Настройки»** → карточка
   **«Распознавание речи»** → у строки **«Whisper small — точная (190 МБ)»** (★ рекомендуем) нажмите **«Скачать»**.
   Нужен интернет (лучше Wi-Fi). Прогресс виден тут же. После скачивания интернет для субтитров не нужен.

   Какую модель выбрать:

   | Модель | Качество русского | Скорость | Размер |
   |---|---|---|---|
   | **Whisper small** (рекомендуем) | хорошее, со знаками препинания | минута речи — примерно 1–3 минуты работы | 190 МБ |
   | Whisper base | средне, со знаками препинания | в 2–3 раза быстрее small | 60 МБ |
   | Whisper large-v3-turbo | лучшее | заметно медленнее small, только для мощных телефонов (от 8 ГБ памяти) | 550 МБ |
   | Vosk, русский | слабое, без знаков препинания | очень быстро | 45 МБ |

   Скорость сильно зависит от телефона. Whisper работает только на 64-битных телефонах (почти все
   телефоны с 2017 года); на остальных строки Whisper помечены «не работает на этом телефоне» — берите Vosk.
   В поле **«Модель по умолчанию»** выберите ту, которой распознавать, и нажмите **«Сохранить»**.
   Ненужную модель можно удалить кнопкой **«Удалить»** — освободится место.
2. **Источник.** «Настройки» → **«Добавить источник»** → «Название», «Тип» → **«Выбрать папку на телефоне»** →
   в системном окне откройте папку с сериями/фильмом/записями стрима → **«Использовать эту папку»** →
   **«Разрешить»**. Приложение увидит только эту папку. → **«Сохранить источник»**.
3. Для стримов и блогеров сразу откроется **«Рамка вебкамеры»** — потяните рамку на окошко камеры,
   **«Сохранить рамку»**. Кнопка **«Найти лицо автоматически»** работает и в приложении.
4. **Расписание** — как в INSTRUCTION.md, шаг B5.

## 3. Каждый день

Как в части C INSTRUCTION.md, с двумя отличиями:

* Видео не из папки источника можно открыть кнопкой **«Выбрать видео на телефоне»** (вкладка «Клип»,
  источник «Выбранные видео»). Ограничения по размеру нет — файл не копируется.
* На экране **«Готовый клип»**: **«Поделиться»** открывает обычное окно Android «Поделиться» — выберите
  **TikTok**. **«Открыть в галерее»** — посмотреть клип в плеере телефона.
  Клип уже лежит в галерее: **Movies/TikTokClips**. Субтитры `.srt` и `.ass` — в **Documents/TikTokClips**.

Пока идёт нарезка, можно выключить экран или свернуть приложение — в шторке уведомлений видно
«Собираю видео · 45%».

## 4. Вкладка «Моменты»: что понравилось зрителям

Приложение показывает минуты стримов и видео, на которые зрители реагировали сильнее всего:

* **Twitch** — из каких мест записи эфира зрители нарезали больше всего клипов (и сколько у клипов просмотров);
* **YouTube: стримы** — прошедшие трансляции; **YouTube: каналы** — обычные видео (без Shorts).
  Кнопка **«Найти моменты по комментариям»** читает до 500 комментариев и находит минуты, которые зрители
  упоминают чаще всего («12:34 ахах»).

**Видео приложение не скачивает.** Запись эфира или видео должна лежать в папке источника (свои записи
скачиваются в панели автора Twitch или в YouTube Studio, чужие — только с разрешения автора).
Нажмите **«Резать»** у момента → приложение спросит, какой файл — эта запись (файл с датой эфира в имени
отмечен «★ похоже, это она»), запомнит ответ и откроет экран «Выбор момента» сразу на этой минуте
(на 3 секунды раньше — зрители пишут время чуть позже начала). Дальше — как обычно: «Сделать клип».
Кнопки **«Клип ↗»** и **«YouTube ↗»** открывают оригинал, чтобы посмотреть момент.

### 4.1. Что указать в источнике

«Настройки» → источник (тип «Стрим» или «Блогер»):

* **Twitch: логин** — из адреса канала `twitch.tv/логин`;
* **YouTube: ID канала** — начинается с `UC`. Где взять: страница канала в YouTube → описание канала
  («…ещё») → **«Поделиться каналом»** → **«Копировать идентификатор канала»**.

### 4.2. Ключи (бесплатно, один раз)

Ключи вводятся в «Настройки» → **«Ключи для вкладки „Моменты“»** → **«Сохранить ключи»**.
Хранятся только на телефоне; в настройках потом видны лишь последние 4 символа.

**Twitch (Client ID и Client Secret), ~5 минут:**

1. Войдите на **dev.twitch.tv/console** своим аккаунтом Twitch. Twitch требует включённую
   двухфакторную защиту: «Настройки» Twitch → «Безопасность и конфиденциальность» → «Двухфакторная аутентификация».
2. **Applications** → **Register Your Application**.
3. Name — любое уникальное латиницей, например `narezka-` и ваш ник; OAuth Redirect URLs — `http://localhost`;
   Category — **Application Integration**; Client Type — **Confidential** → **Create**.
4. У приложения нажмите **Manage** → скопируйте **Client ID** → нажмите **New Secret** → скопируйте **Client Secret**.

**YouTube Data API (ключ), ~5 минут:**

1. Откройте **console.cloud.google.com** (аккаунт Google) → вверху **«Выберите проект»** → **«Новый проект»** → **«Создать»**.
2. Меню → **«API и сервисы»** → **«Библиотека»** → найдите **YouTube Data API v3** → **«Включить»**.
3. **«API и сервисы»** → **«Учётные данные»** → **«Создать учётные данные»** → **«Ключ API»** → скопируйте ключ.
   Банковская карта не нужна.

Бесплатного лимита YouTube (10 000 единиц в сутки) хватает с запасом: обновить список канала — 2 единицы,
найти моменты одного видео — до 5. Результаты хранятся 30 минут (списки) и 6 часов (моменты); кнопка
**«Обновить»** запрашивает заново.

## 5. Если что-то пошло не так

| Проблема | Причина | Что сделать |
|---|---|---|
| ⚠ «Модель распознавания речи не скачана» | Не скачана модель | «Настройки» → «Распознавание речи» → «Скачать» |
| Субтитры с ошибками | Модель ошиблась (у Vosk ошибок больше всего) | Скачайте Whisper small и выберите её в «Модель по умолчанию». Или исправьте строки на экране «Готовый клип» → «Пересобрать». Или положите рядом с видео файл `.srt` с тем же именем и включите «Взять текст из файла .srt рядом с видео» |
| Распознавание идёт очень долго | Большая модель на небыстром телефоне | Выберите Whisper base (или Vosk) в «Модель по умолчанию». Клипы короче — распознаются быстрее |
| «Не удалось открыть модель …» / «Whisper не смог распознать речь» | Не хватило памяти или файл модели повреждён | Закройте другие приложения. «Удалить» модель и «Скачать» снова. Или выберите модель поменьше |
| ⚠ «Звук этого файла телефон не декодирует — добавлена тишина» | Звук в формате AC3/DTS (бывает в MKV-фильмах), не все телефоны его понимают | Возьмите файл со звуком AAC (обычно MP4) или переконвертируйте файл на компьютере |
| «Android не умеет читать этот файл» / «Телефон не умеет декодировать это видео» | Формат AVI или редкий кодек | Используйте MP4 (H.264/H.265), MKV, WEBM или MOV |
| «Нет доступа к папке источника» | Папку переместили или доступ сбросился | «Настройки» → источник → «Выбрать папку на телефоне» заново |
| Нарезка остановилась, когда свернул приложение | Режим экономии батареи | Настройки телефона → Приложения → Нарезка → Батарея → **«Без ограничений»**. Прерванная задача сама начнётся заново, когда откроете приложение |
| Клипа нет в галерее | Галерея ещё не обновилась | Откройте «Файлы» → Movies → TikTokClips, или нажмите «Открыть в галерее» |
| «Нужен ключ Twitch / YouTube» на вкладке «Моменты» | Ключи не введены | Раздел 4.2 |
| «Twitch не принял ключи» | Опечатка в Client ID / Secret или Secret пересоздан | Скопируйте оба заново (Manage → New Secret) и сохраните |
| «YouTube не принял ключ» / «не включён YouTube Data API v3» | Ключ с ошибкой или API не включено в проекте | Раздел 4.2, шаг 2 — «Включить» |
| «Дневной лимит запросов YouTube исчерпан» | Слишком много запросов за сутки | Подождите до завтра (лимит обновляется около 10:00 по Москве) |
| «Twitch/YouTube недоступен» | Нет интернета или сервис не открывается из вашей сети | Проверьте интернет, попробуйте другую сеть (Wi-Fi / мобильная) |
| Нет моментов у записи Twitch | Зрители не делали клипы, или запись старше срока хранения Twitch (7–60 дней) | Попробуйте свежий эфир |
| «В комментариях нет таймкодов» | Видео малопопулярное или комментарии выключены | Используйте «Предложить моменты» (по звуку) на экране клипа |
| «Сайт моделей ответил …» / «Не удалось скачать модель» / «Скачался не тот файл» | Нет интернета или сайт моделей недоступен (модели Whisper — с huggingface.co, Vosk — с alphacephei.com) | Подключитесь к Wi-Fi и нажмите «Скачать» ещё раз — скачивание продолжится с того же места |

## 6. Честно об ограничениях приложения

* Распознавание речи работает без интернета. Whisper на телефоне медленнее, чем на компьютере: на клип
  в минуту — несколько минут ожидания (зависит от телефона и модели). Ошибки бывают у любой модели —
  строки легко поправить вручную. Скорость на реальных телефонах заранее не измерялась.
* Форматы — только те, что понимают кодеки телефона (AVI не поддерживается, звук AC3/DTS — не везде).
* «Моменты» работают для Twitch и YouTube. Для фильмов и сериалов открытых данных о том, какие сцены
  пересматривают, нет — там моменты подсказываются по звуку («Предложить моменты»).
* Видео из Twitch и YouTube приложение не скачивает — только показывает, с какой минуты резать.
