# Приложение «Нарезка» (APK): инструкция

Приложение для Android 8 и новее. Режет из ваших видео короткие вертикальные клипы 1080×1920 для TikTok:
с субтитрами, зеркалом и баннером. Termux и сервер не нужны: открыли значок — работаете. Видео собирается
аппаратным кодировщиком телефона.

Внизу три вкладки:

* **Подборка** — что смотреть и резать: популярные и лучшие по IMDb сериалы и фильмы, весь мир и Россия;
* **Клип** — видео с телефона: «⚡ Быстрый клип» одной кнопкой или вручную, баннер (картинка или видео), готовые клипы;
* **Настройки** — ночная нарезка, ключ TMDB, распознавание речи, качество видео.

Минимум работы: один раз сохраните **шаблон** (4.3) и включите **ночную нарезку** (4.6) — утром останется нажать
«Поделиться» и вставить готовую подпись в TikTok.

## 1. Установка

1. Скачайте `Narezka.apk` (раздел Releases на GitHub) и откройте файл на телефоне.
2. Android спросит: «Разрешить установку приложений из этого источника?» — **Настройки** → включите
   переключатель → назад → **Установить**. Новая версия ставится поверх старой.
3. Откройте **«Нарезка»**. На вопрос про уведомления нажмите **Разрешить** — в уведомлении виден прогресс,
   и Android не закрывает приложение, пока собирается клип.

## 2. Первая настройка (один раз)

### 2.1. Распознавание речи (для субтитров)

**«Настройки»** → **«Распознавание речи»** → у строки **«Whisper small — точная (190 МБ)»** (★ рекомендуем) →
**«Скачать»**. Нужен интернет (лучше Wi-Fi), дальше субтитры работают без интернета.

| Модель | Качество русского | Скорость | Размер |
|---|---|---|---|
| **Whisper small** (рекомендуем) | хорошее, со знаками препинания | минута речи — примерно 1–3 минуты работы | 190 МБ |
| Whisper base | средне, со знаками препинания | в 2–3 раза быстрее small | 60 МБ |
| Whisper large-v3-turbo | лучшее | заметно медленнее, только для мощных телефонов (от 8 ГБ памяти) | 550 МБ |
| Vosk, русский | слабое, без знаков препинания | очень быстро | 45 МБ |

Скорость сильно зависит от телефона. Whisper работает на 64-битных телефонах (почти все с 2017 года).
В поле **«Модель по умолчанию»** выберите модель → **«Сохранить»**. Ненужную модель можно **«Удалить»**.

### 2.2. Ключ TMDB (для «Подборки», бесплатно, ~5 минут)

1. Зарегистрируйтесь на **themoviedb.org** (нужна только почта).
2. Аватар → **«Настройки»** → **«API»** → **«Создать»** (Request an API Key) → тип **Developer** → примите условия.
3. Форма: название приложения — любое (например, «Нарезка»), адрес — любой (например, `http://localhost`),
   описание — «личное приложение для подбора фильмов».
4. Скопируйте **«Ключ API»** (32 символа) или **«Токен доступа к API»** (длинный, начинается с `eyJ`).
5. В приложении: **«Настройки»** → **«Ключ TMDB»** → вставьте → **«Сохранить ключ»**.
   Потом в поле видны только последние 4 символа.

## 3. Подборка

Три переключателя:

* **Мир / Россия** — все страны или русские и советские картины (язык оригинала — русский);
* **Сериалы / Фильмы**;
* **Популярное / Лучшее по IMDb** — что смотрят сейчас или лучшие по рейтингу (сортировка по рейтингу IMDb).

У каждого названия: год, **рейтинг IMDb** (и число голосов), рейтинг TMDB, короткое описание, кнопки
**«IMDb ↗»** и **«TMDB ↗»** — открыть страницу с подробностями. Внизу — **«Показать ещё»**.

Рейтинги IMDb приложение берёт из открытого набора данных IMDb (для личного использования): при первом
открытии «Подборки» и потом раз в неделю скачивается файл около 8 МБ — вверху видно «Загружаю рейтинги IMDb…».
Ключ для IMDb не нужен. Видео приложение не скачивает.

## 4. Клип

### 4.1. Быстро: одна кнопка

1. **«Выбрать видео на телефоне»** — серия или фильм из памяти телефона (файл не копируется, размер любой).
2. **«⚡ Быстрый клип»** — приложение само найдёт лучший момент и соберёт клип **по шаблону** (4.3).
   Прогресс — вверху вкладки. Когда готово, клип откроется сам.

### 4.2. Вручную

1. Видео — как выше.
2. Отрезок: ползунки **«Начало»** / **«Конец»**, **−1 с / +1 с**, **«Начало = позиция»**, **«▶ Проиграть отрезок»**.
3. **«Автоподбор моментов»** — самые яркие места: громкие всплески, плотная и эмоциональная речь (восклицания, смех,
   крик, перепалка — если рядом с видео лежит `.srt` с тем же именем), быстрый монтаж. Нажмите на момент — ползунки
   встанут на него. Длина момента — в «Настройках».
4. **Настройки клипа:** зеркало, субтитры, язык, стиль; **«Взять текст из файла .srt»**, если он есть.
5. **Баннер** (4.4).
6. **«Сделать клип»** → прогресс вверху (можно **«Отменить»**) → клип откроется сам.

### 4.3. Шаблон

Настройте клип один раз (зеркало, субтитры, стиль, язык, баннер) → **«Сохранить как шаблон»**. По шаблону собираются
«Быстрый клип» и ночная нарезка; при выборе нового видео эти же значения подставляются и в ручной режим.

### 4.4. Баннер — картинка или видео

**«Выбрать картинку или видео»** → PNG / JPG или короткое **MP4** из файлов телефона (логотип, надпись, «подпишись»).

* Видео-баннер крутится по кругу без звука (берутся первые 6 секунд).
* **«Сверху» / «По центру» / «Снизу»** и **«Ширина»**. Баннер всегда остаётся в безопасной зоне TikTok — не под
  верхними вкладками, кнопками справа и подписью снизу — и не перекрывает субтитры: при «Снизу» субтитры поднимаются
  над баннером. «Сверху» — над видео, на размытом фоне: там его видно лучше всего.
* **«Тёмная подложка (лучше видно)»** — полупрозрачный тёмный прямоугольник под баннером, включена сразу.
* **«Убрать зелёный фон»** — для анимаций на зелёном фоне (хромакей): в клипе фон станет прозрачным
  (в предпросмотре зелёный ещё виден).
* Предпросмотр 9:16 показывает, где будут баннер и субтитры.

### 4.5. Готовый клип

**«Поделиться»** → TikTok. Подпись с хэштегами (название, сезон и серия из имени файла, `#сериал`/`#фильм`, `#кино`…)
**копируется сама** — в TikTok остаётся вставить её в описание. Также: **«Скопировать подпись»**, **«Открыть в галерее»**,
правка строк субтитров → **«Пересобрать»**. Все клипы — внизу вкладки, **«Готовые клипы»** (ночные помечены 🌙).
Файлы: **Movies/TikTokClips**, субтитры `.srt`/`.ass` — **Documents/TikTokClips**.

### 4.6. Ночная нарезка

**«Настройки»** → **«Ночная нарезка»** → **«Выбрать папку на телефоне»** (например, папка с сезоном) → **«Клипов за ночь»**
(по умолчанию 3) → **«Включена»** → **«Сохранить»**.

Ночью, когда телефон **на зарядке и им не пользуются** (с 21:00 до 9:00, раз в сутки), приложение берёт следующие
по порядку видео из папки, находит в каждом лучший момент и собирает клипы по шаблону. Утром — уведомление
«Ночная нарезка: готово клипов — N»; нажмите — откроется «Клип» → «Готовые клипы».

* **«Нарезать сейчас»** — запустить сразу, не дожидаясь ночи.
* **«Начать папку заново»** — снова пройти папку с первого видео.
* Чтобы Android не мешал: настройки телефона → Приложения → Нарезка → Батарея → **«Без ограничений»**.

## 5. Если что-то пошло не так

| Проблема | Причина | Что сделать |
|---|---|---|
| «Нужен ключ TMDB» в «Подборке» | Ключ не введён | Раздел 2.2 |
| «TMDB не принял ключ» / «TMDB недоступен» | Опечатка в ключе или сайт не открывается из вашей сети | Скопируйте ключ заново; проверьте интернет |
| Нет рейтингов IMDb, «IMDb недоступен» | Файл рейтингов не скачался | Проверьте интернет и откройте «Подборку» снова — загрузка повторится |
| ⚠ «Модель распознавания речи не скачана» | Модель не скачана | «Настройки» → «Распознавание речи» → «Скачать» |
| «Не удалось скачать модель» / «Скачался не тот файл» | Нет интернета или сайт моделей недоступен | Wi-Fi → «Скачать» ещё раз (докачает с того же места) |
| Субтитры с ошибками | Модель ошиблась | Whisper small в «Модель по умолчанию»; или поправьте строки на готовом клипе → «Пересобрать»; или положите `.srt` рядом с видео |
| Распознавание идёт очень долго | Большая модель на небыстром телефоне | Whisper base или Vosk; клипы покороче |
| «Не удалось открыть модель …» | Не хватило памяти или файл повреждён | Закройте другие приложения; «Удалить» модель и «Скачать» снова |
| «Баннер не удалось открыть — клип собран без баннера» | Файл удалили или нет доступа | «Другой файл» и соберите заново |
| Ночью ничего не нарезалось | Телефон не стоял на зарядке без дела, или Android ограничил приложение | Батарея → «Без ограничений»; проверьте «Нарезать сейчас» |
| «Новых видео в папке нет — всё уже нарезано» | Все видео папки уже пройдены | Добавьте видео или «Начать папку заново» |
| Зелёный фон баннера не исчез | Фон не чисто-зелёный | Включите «Убрать зелёный фон»; нужен ярко-зелёный фон (хромакей) |
| ⚠ «Звук этого файла телефон не декодирует — добавлена тишина» | Звук AC3/DTS (бывает в MKV) | Файл со звуком AAC (обычно MP4) |
| «Телефон не умеет декодировать это видео» | AVI или редкий кодек | MP4 (H.264/H.265), MKV, WEBM, MOV |
| Сборка остановилась, когда свернули приложение | Экономия батареи | Настройки телефона → Приложения → Нарезка → Батарея → «Без ограничений» |
| Клипа нет в галерее | Галерея ещё не обновилась | «Файлы» → Movies → TikTokClips, или «Открыть в галерее» |

## 6. Честно об ограничениях

* Видео приложение не скачивает: серии и фильмы берёте из памяти телефона сами.
* «Автоподбор моментов» — оценка по звуку, речи и монтажу, а не данные о том, что пересматривают зрители
  (таких открытых данных для фильмов и сериалов нет). Проверяйте момент кнопкой «▶ Проиграть отрезок».
* Whisper на телефоне медленнее, чем на компьютере; скорость на реальных телефонах заранее не измерялась.
* Форматы — только те, что понимают кодеки телефона (AVI не поддерживается, звук AC3/DTS — не везде).
