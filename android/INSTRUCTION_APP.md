# Приложение «Нарезка» (APK): инструкция

Приложение для Android 8 и новее. Режет из записей эфиров (и любых видео с телефона) короткие вертикальные клипы
1080×1920 для TikTok: игра сверху, вебкамера снизу, субтитры, баннер, готовая подпись с хэштегами.
Видео собирается аппаратным кодировщиком телефона.

Внизу две вкладки:

* **Клип** — «📂 Загрузить видео» → приложение само находит вебкамеру и экран → моменты → клип;
* **Настройки** — подпись к клипам, распознавание речи, качество видео.

Никаких списков и папок: источник — одно видео, которое вы выбрали на телефоне.

## 1. Установка

1. Скачайте `Narezka.apk` (раздел Releases на GitHub) и откройте файл на телефоне.
2. «Разрешить установку из этого источника» → **Установить**. Новая версия ставится поверх старой.
3. Откройте **«Нарезка»** → **Разрешить** уведомления (в них виден прогресс, и Android не закрывает приложение).
4. Настройки телефона → Приложения → Нарезка → Батарея → **«Без ограничений»** — чтобы сборка не прерывалась.

## 2. Первая настройка (один раз)

### 2.1. Распознавание речи (для субтитров)

**«Настройки»** → **«Распознавание речи»** → **«Whisper small — точная (190 МБ)»** (★ рекомендуем) → **«Скачать»**
(лучше по Wi-Fi). Дальше субтитры работают без интернета. Медленный телефон — Whisper base; совсем быстро, но хуже — Vosk.

### 2.2. Подпись к клипам

**«Настройки»** → **«Подпись к клипам»**: **имя стримера** и **Twitch-логин** (или ссылку на канал — логин приложение
возьмёт само) → **«Сохранить подпись»**. Из них получается подпись для TikTok: «Стример Вася · эфир 28.10» и хэштеги
`#стримервася #vasya_live #твич #стрим #нарезки #моменты`. Можно оставить пустым.

## 3. Клип

### 3.1. Загрузить видео

**«Клип»** → **«📂 Загрузить видео»** → выберите запись эфира в галерее или в «Файлах». Если в имени файла есть дата
(`stream_2026-10-28.mp4`), она попадёт в подпись. Другое видео — кнопка **«Другое видео»**.

### 3.2. Экран и вебкамера — сами

Сразу после загрузки приложение смотрит несколько кадров из разных мест записи и ищет **вебкамеру**: прямоугольник,
края которого стоят на месте, а внутри всё время что-то движется (или лицо). **Экран** (верх клипа) подрезается так,
чтобы вебкамера в него по возможности не попадала; чёрные полосы по краям видео отрезаются.

Карточка **«Кадр: экран и вебкамера»** показывает результат и схему клипа 9:16:

* «✓ Вебкамера найдена автоматически» — клип будет **«Экран + вебкамера»**: игра сверху, камера снизу;
* «Вебкамеры не видно» или «Камера на весь кадр» — клип будет **«Один кадр»**.

Переключить вручную — кнопки **«Экран + вебкамера» / «Один кадр»**.

**«Настроить рамки»** — поправить вручную: рамка **«Вебкамера»** и рамка **«Экран»** (переключатель сверху); тяните рамку
пальцем, углы — за белые кружки; ползунок «Кадр» — посмотреть другое место записи; **«Найти автоматически»** — искать
заново; **«Готово»** — сохранить; **«Без вебкамеры (один кадр)»**. Рамки запоминаются для этого видео.

### 3.3. Файл чата (необязательно)

**«💬 Файл чата записи» → «Добавить»** → выберите файл чата этого эфира. Тогда моменты ищутся по **реакции зрителей**:
минуты, где чат писал в разы чаще обычного, реакции (KEKW, LUL, «ахах», 😂) весят больше; начало момента — за 15 секунд
до всплеска. Подходят: JSON формата TwitchDownloader (`.json`, `.json.gz`), текстовый лог `[0:01:23] ник: сообщение`,
лог Chatterino `[19:01:23] ник: …` (время отсчитывается от первого сообщения), JSON с `time_in_seconds`.
**«Убрать»** — отвязать файл. Без чата моменты ищутся **по звуку**: крики, смех, громкие всплески, эмоциональная речь.

### 3.4. Быстро и вручную

1. **«⚡ Быстрый клип»** — лучший момент → клип по шаблону (3.5) с рамками этого видео. Прогресс вверху, готовый клип откроется сам.
2. Или вручную: ползунки **«Начало» / «Конец»**, **«Автоподбор моментов»** → нажмите момент → **«Настройки клипа»**
   (зеркало, субтитры, язык, стиль) → **Баннер** (3.6) → **«Сделать клип»**.

### 3.5. Шаблон

Настройте клип (зеркало, субтитры, стиль, язык, баннер) → **«Сохранить как шаблон»**. По шаблону собирается
«⚡ Быстрый клип»; экран и вебкамера берутся из карточки «Кадр» этого видео.

### 3.6. Баннер

**«Выбрать картинку или видео»** → PNG / JPG или короткое **MP4** (крутится по кругу без звука, до 6 секунд).
**«Сверху» / «По центру» / «Снизу»**, **«Ширина»**, **«Тёмная подложка»** (включена сразу), **«Убрать зелёный фон»**
(для анимаций на зелёном фоне). Баннер всегда в безопасной зоне TikTok и не перекрывает субтитры.

### 3.7. Готовый клип

**«Поделиться»** → TikTok: подпись **копируется сама** (2.2), в TikTok остаётся вставить. Также: «Скопировать подпись»,
«Открыть в галерее», правка субтитров → «Пересобрать». Все клипы — внизу вкладки «Клип», **«Готовые клипы»**.
Файлы: **Movies/TikTokClips**, субтитры — **Documents/TikTokClips**.

## 4. Чтобы клипы приносили деньги, а не баны

* Режьте стримеров, которые **разрешили** нарезки (программы нарезок, договорённость) — иначе жалобы и блокировки.
* **Избегайте моментов с музыкой** в эфире: за чужую музыку бывают жалобы и страйки, лицензия Twitch на TikTok не распространяется.
* **Перерабатывайте**: субтитры, раскладка, баннер. Голые перезаливы TikTok считает «неоригинальным контентом» и не
  монетизирует; для программы TikTok видео должно быть не короче 1 минуты.
* Не накручивайте просмотры: программы нарезок платят за проверенные просмотры и отключают за ботов.

## 5. Если что-то пошло не так

| Проблема | Причина | Что сделать |
|---|---|---|
| «Вебкамеры не видно», а она есть | Камера без рамки на похожем фоне или лицо не повёрнуто к камере | «Настроить рамки» → поставьте рамку пальцем → «Готово» |
| Рамка вебкамеры захватила лишнее | Рядом с камерой неподвижная часть игры | «Настроить рамки» → подтяните углы |
| В клипе камера не на месте | Стример сменил макет посреди эфира | «Настроить рамки» на нужном кадре (ползунок «Кадр») |
| ⚠ «Модель распознавания речи не скачана» | Модель не скачана | «Настройки» → «Распознавание речи» → «Скачать» |
| «Не удалось скачать модель» | Нет интернета | Wi-Fi → «Скачать» ещё раз (докачает) |
| «Файл чата … не удалось прочитать — ищу по звуку» | Формат чата не распознан | Нужен один из форматов из 3.3 |
| Моменты по чату сдвинуты | Лог Chatterino начинается не с начала эфира | Удалите сообщения до эфира или поправьте ползунком |
| «Баннер не удалось открыть» | Файл удалили | «Другой файл» |
| Субтитры с ошибками | Модель ошиблась | Whisper small; правка строк → «Пересобрать» |
| ⚠ «Звук этого файла телефон не декодирует» | AC3/DTS в MKV | Запись со звуком AAC (MP4) |
| Сборка остановилась | Экономия батареи | Батарея → «Без ограничений» |
| Видео пропало из «Клипа» | Файл удалили или переместили | «📂 Загрузить видео» ещё раз |

## 6. Честно об ограничениях

* Видео приложение не скачивает — только режет файлы, которые лежат на телефоне.
* Автоподбор рамок — оценка по нескольким кадрам: проверьте схему в карточке «Кадр» перед сборкой.
* Моменты по звуку — оценка, по чату — реальная реакция зрителей; проверяйте момент перед публикацией.
* Whisper на телефоне медленнее, чем на компьютере.
