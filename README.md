# tiktok-clipper

Нарезка вертикальных клипов для TikTok (1080×1920) из фильмов, сериалов, стримов и видео блогеров
с управлением **с телефона** через веб-интерфейс (PWA). Пошаговая инструкция для пользователя —
[INSTRUCTION.md](INSTRUCTION.md).

Есть и **Android-приложение (APK)** без Termux: папка `android/` — Gradle-проект на Java,
сборка видео аппаратными кодеками телефона (MediaCodec + OpenGL), распознавание речи Vosk,
тот же интерфейс внутри WebView. Сборка — [android/BUILD_APK.md](android/BUILD_APK.md),
инструкция пользователя — [INSTRUCTION_APP.md](INSTRUCTION_APP.md).

## Что умеет

* **Расписание с чередованием**: блоки по `posts_per_block` постов из одного источника, типы по кругу
  (`type_order`), источники внутри типа по очереди. Начатый блок «замораживается» в `state.json`,
  поэтому добавление/удаление источников и пропущенные дни не ломают порядок. Экран «Сегодня»:
  пост N/3, дата, какой файл брать, свежее видео с YouTube (RSS, без ключей) или Twitch (ключи из env).
* **Нарезка** одним вызовом ffmpeg: `single` (кадр по центру на размытом фоне, с увеличением) или
  `split` (экран сверху + вебкамера снизу + полоса субтитров, доли высот в профиле).
  Нет рамки вебкамеры → откат в `single` с предупреждением. Нет звука → тишина AAC.
  Выход: H.264 yuv420p + AAC, `+faststart`, длительность = END−START (±0,1 с, проверяется после сборки).
* **Зеркало** (`hflip`) всей собранной картинки **до** наложения субтитров — текст не отражается.
* **Субтитры**: таймкоды по словам, 2–3 слова на экране, подсветка текущего слова, свой шрифт
  Montserrat ExtraBold (OFL, кириллица) в `fonts/`, ASS через libass, `.srt` и `.ass` рядом с клипом.
  Текст всегда внутри безопасной зоны TikTok (x 60–900, y 220–1440 из 1080×1920): ширина строки
  считается по таблице ширин глифов (`fonts/metrics.json`), при необходимости шрифт уменьшается или
  строка делится на 2 ряда. Правка строк в интерфейсе и «Пересобрать» — без повторного распознавания.
  Источник текста: распознавание или готовый `.srt` рядом с видео.
* **Распознавание речи** со сменными бэкендами: `faster-whisper` (ПК/сервер/Docker), `whisper.cpp`
  (Termux), `off`. Модель по умолчанию: tiny на телефоне, small на ПК. Фильтр типичных
  «галлюцинаций» Whisper («Субтитры сделал…» и т.п.).
* **«Предложить моменты»**: громкость по секундам (считает ffmpeg, кэшируется) + плотность речи
  из `.srt`/транскрипта; неперекрывающиеся окна, привязка начала к началу реплики.
* **Очередь задач** в фоне с прогрессом, состояние в `data/jobs.json`; прерванные задачи после
  перезапуска выполняются заново. В Termux на время задач берётся `termux-wake-lock`.
* **Готовый клип**: превью, «Поделиться» (Web Share API с файлом), «Скачать», «Опубликовано».
  В Termux клип пишется в `Movies/TikTokClips` и отдаётся в `termux-media-scan` (если стоит Termux:API).
* **Безопасность**: по умолчанию только `127.0.0.1`. На любом другом адресе без `CLIPPER_TOKEN`
  (≥ 8 символов) сервер не стартует. С токеном все страницы, API, видео и клипы требуют входа
  (cookie HttpOnly/SameSite=Strict с HMAC-значением, не сам пароль) или `Authorization: Bearer`;
  ограничение попыток входа. Без токена запросы принимаются только с loopback и с Host=localhost
  (защита от DNS-rebinding и случайного проброса через прокси). Пути к файлам не выходят за `MEDIA_ROOT`.
* Скачивания фильмов, пиратских источников и yt-dlp нет: вход — только файлы в папках источников.

## Устройство

```
clipper.py            CLI (запасной интерфейс): serve, check, today, publish, skip, postpone, undo, make, moments
tclip/config.py       пути, sources.json/settings.json, профили, стили субтитров
tclip/schedule.py     чередование и расписание
tclip/render.py       фильтр-граф ffmpeg (single/split → hflip → ass → yuv420p)
tclip/subtitles.py    группировка слов, ASS/SRT, безопасная зона, правки
tclip/asr.py          faster-whisper / whisper.cpp / off
tclip/moments.py      поиск моментов
tclip/jobs.py         персистентная очередь
tclip/pipeline.py     задачи: клип, пересборка, моменты
tclip/server.py       Flask + waitress, авторизация, API
tclip/static/         PWA: index.html, app.js, app.css, sw.js, manifest, иконки (без CDN)
fonts/                Montserrat ExtraBold + лицензия OFL + таблица ширин
install.sh, start.sh  Termux/Linux; Dockerfile, docker-compose.yml — ПК/VPS
tests/                pytest + Playwright (Node) UI-прогон
```

Данные: `data/` (`CLIPPER_DATA`), исходники: `MEDIA_ROOT` (`CLIPPER_MEDIA`; в Termux —
`~/storage/shared/TikTokClipper`), клипы: `CLIPPER_OUTPUT` (в Termux — `~/storage/shared/Movies/TikTokClips`).

Зависимости ядра — только `flask` и `waitress` (чистый Python, ставятся в Termux). Остальное по желанию:
`faster-whisper`, `opencv-python-headless` (ПК/Docker), whisper.cpp (собирается `install.sh --whisper`).

## Docker

Образ на `ubuntu:24.04` (ffmpeg 6.1 с libass и libx264, Python 3.12) + `faster-whisper` и OpenCV 4.
`docker-entrypoint.sh` запускает сервер от имени владельца папки `/data`, поэтому и папки, созданные
самим Docker (root), и папки пользователя доступны для записи. Без `CLIPPER_TOKEN` `docker compose`
не запустится (`${CLIPPER_TOKEN:?…}`), а сам сервер на 0.0.0.0 без токена завершается с кодом 2.
Профиль `https` поднимает Caddy с автоматическим сертификатом для `DOMAIN`.

## Допущения

1. Пользователь сам кладёт видеофайлы в папки (на телефоне — через «Файлы», на ПК — в `media/`);
   программа ничего не скачивает.
2. Время клипа: 1 с – 10 мин; загрузка с телефона — до 300 МБ и 15 мин (настраивается).
3. Безопасная зона TikTok взята с запасом: справа 180 px под колонку иконок, снизу 480 px под подпись
   и музыку, сверху 220 px под вкладки. Субтитры центрируются по безопасной зоне (x = 480), а не по кадру.
4. «Текущий пост» сдвигается только кнопками «Опубликовано»/«Пропустить». После публикации следующий
   пост назначается на `max(дата поста, сегодня) + interval_days`.
5. Блогер/стример без вебкамеры — это `single` с предупреждением, а не ошибка.
6. Кириллический пароль работает через форму входа; для заголовка `Authorization: Bearer` и `.env`
   рекомендуется пароль латиницей.
7. «Поделиться» с файлом браузеры разрешают только в безопасном контексте (`127.0.0.1` или https);
   в остальных случаях интерфейс честно предлагает «Скачать».
