# Инструкция: нарезка клипов для TikTok с телефона

Эта программа делает из фильмов, серий, записей стримов и видео блогеров вертикальные клипы для TikTok:
1080×1920, с крупными субтитрами и (по желанию) зеркальным отражением. Ещё она ведёт расписание:
подсказывает, что публиковать сегодня.

Управляете вы всем **с телефона, через браузер**. Сама программа (сервер) работает либо прямо
на телефоне Android (в приложении Termux), либо на домашнем компьютере.

> **Как читать команды.** Команды набираются в Termux (чёрное окно с текстом) или в терминале компьютера.
> Набирайте их точно как написано, затем нажмите **Enter** (на клавиатуре Termux — стрелка ↵).
> Под каждой командой написано, что она делает и что должно появиться на экране.
> Длинную команду удобнее скопировать из этой инструкции: долгое нажатие → «Копировать»,
> затем в Termux долгое нажатие на экран → «Paste» (Вставить).

Скриншоты экранов лежат в папке `docs/screenshots` — по ним можно сверяться.

## Часть A. Установка (один раз)

### A1. Android: установка на сам телефон

1. **Установите F-Droid.** Откройте в браузере телефона сайт **f-droid.org**, нажмите «Скачать F-Droid»
   и установите скачанный файл (телефон спросит разрешение на установку из браузера — разрешите).
2. **Установите Termux из F-Droid.** Откройте F-Droid, в поиске наберите **Termux**, установите.
   ⚠ Не ставьте Termux из Google Play: там старая версия, с которой ничего не заработает.
3. **Откройте Termux.** Появится чёрный экран с текстом и строкой, которая заканчивается на `$`.
   Это место для команд.
4. Наберите:
   ```
   pkg update
   ```
   *Что делает:* обновляет список программ Termux.
   *Что увидите:* бегущие строки. Если появится вопрос с буквами `[Y/n]` или `(Y/I/N/O/D/Z)` — просто
   нажмите Enter. Готово, когда снова появится строка с `$`.
5. Наберите:
   ```
   pkg install python ffmpeg git
   ```
   *Что делает:* ставит Python (на нём написана программа), ffmpeg (режет и склеивает видео) и git.
   *Что увидите:* вопрос `Do you want to continue? [Y/n]` — нажмите Enter. Установка займёт 2–10 минут.
6. Наберите:
   ```
   termux-setup-storage
   ```
   *Что делает:* даёт Termux доступ к памяти телефона (чтобы брать фильмы и сохранять клипы в галерею).
   *Что увидите:* окно «Разрешить Termux доступ к фото и мультимедиа?» — нажмите **Разрешить**.
7. **Скачайте программу на телефон.** Сохраните архив `tiktok-clipper.zip` в папку «Загрузки» (Download)
   телефона.
8. **Установите программу одной командой:**
   ```
   python -m zipfile -e ~/storage/downloads/tiktok-clipper.zip ~ && bash ~/tiktok-clipper/install.sh
   ```
   *Что делает:* распаковывает архив в домашнюю папку Termux и запускает установщик. Он проверит ffmpeg
   и субтитры (libass), поставит нужные части и создаст папки.
   *Что увидите:* строки с зелёными галочками ✔, в конце — **«Установка завершена.»**
   Если увидите красное **✘ ОШИБКА** — прочитайте текст рядом с ней, там написано, что сделать.

   > Если программа лежит у вас на GitHub, вместо шагов 7–8 можно так:
   > `git clone https://github.com/ВАШ_ЛОГИН/tiktok-clipper ~/tiktok-clipper && bash ~/tiktok-clipper/install.sh`

9. **Распознавание речи для субтитров** (по желанию, но без него субтитров не будет):
   ```
   bash ~/tiktok-clipper/install.sh --whisper
   ```
   *Что делает:* собирает на телефоне программу распознавания речи whisper.cpp и скачивает маленькую
   модель **tiny** (около 75 МБ).
   *Что увидите:* много строк сборки. Это долго: **10–30 минут**, телефон может нагреться — это нормально.
   В конце — «✔ whisper.cpp собран», «✔ Модель tiny готова».
   Модель поточнее (base, около 150 МБ): `bash ~/tiktok-clipper/install.sh --model base`.

   > Честно: на телефоне работает только whisper.cpp. Вариант faster-whisper (как на компьютере)
   > в Termux не устанавливается — для него нет готовых частей под Android.
   > Если сборка не удалась, программа всё равно работает: клипы получаются без субтитров,
   > а субтитры можно взять из файла `.srt` (см. часть B, шаг B2).

10. **Запустите сервер:**
    ```
    bash ~/tiktok-clipper/start.sh
    ```
    *Что делает:* запускает программу.
    *Что увидите:* **«Сервер запущен. Откройте в браузере: http://127.0.0.1:8080»**.
    Termux не закрывайте — его можно свернуть кнопкой «Домой».
    В следующий раз можно набирать короче: `clipper` (работает после перезапуска Termux).

### A2. Открыть программу в браузере и добавить на главный экран

1. Откройте **Chrome** на этом же телефоне.
2. В адресной строке наберите **`127.0.0.1:8080`** и нажмите Enter. Откроется экран **«Сегодня»**.
3. Нажмите меню **⋮** (три точки справа вверху) → **«Добавить на главный экран»**
   (или «Установить приложение») → **«Добавить»**.
4. На главном экране появится значок **«Нарезка»**. Дальше открывайте программу им.
   Важно: значок работает, только когда в Termux запущен сервер (шаг A1.10).

### A3. iPhone или слабый телефон: сервер на компьютере или VPS

**Честно:** на iPhone сам сервер запустить нельзя — iOS не позволяет запускать такие программы.
Слабому Android-телефону тоже тяжело (нарезка идёт медленно). В этих случаях программа работает
на компьютере (Windows, Mac, Linux), мини-ПК или арендованном сервере (VPS), а телефон — только пульт.

**Вариант 1. Домашний компьютер с Docker (проще всего):**

1. Установите **Docker Desktop** с сайта docker.com (Windows/Mac) и запустите его.
2. Распакуйте архив `tiktok-clipper.zip` на компьютере, например в папку «Документы».
3. В папке `tiktok-clipper` сделайте копию файла `.env.example` и назовите её **`.env`**.
   Откройте `.env` Блокнотом и впишите после `CLIPPER_TOKEN=` свой пароль — **латинскими буквами и
   цифрами, не короче 8 символов**, например `CLIPPER_TOKEN=MoiParol2026`. Сохраните.
   Без пароля сервер специально не запустится: иначе кто угодно в вашей сети мог бы им управлять.
4. Откройте терминал в этой папке (Windows: в папке нажмите на адресную строку, наберите `cmd`, Enter;
   Mac: правой кнопкой по папке → «Новый терминал по адресу папки») и наберите:
   ```
   docker compose up -d --build
   ```
   *Что делает:* собирает и запускает программу в фоне. Первый раз — 5–15 минут.
   *Что увидите:* в конце строку `Container tiktok-clipper-clipper-1  Started`.
   Если увидите «Задайте пароль CLIPPER_TOKEN в файле .env» — вернитесь к шагу 3.
5. Узнайте адрес компьютера в домашней сети. Windows: наберите `ipconfig` и найдите «IPv4-адрес»,
   например `192.168.1.25`. Mac: «Системные настройки» → «Wi-Fi» → «Подробнее» → «IP-адрес».
6. На телефоне (подключённом к **тому же Wi-Fi**) откройте браузер и наберите
   **`http://192.168.1.25:8080`** (ваш адрес). Появится страница входа — введите пароль из шага 3,
   нажмите **«Войти»**.
7. Добавьте на главный экран: iPhone (Safari) — кнопка «Поделиться» □↑ → «На экран „Домой“».
8. Фильмы и записи стримов кладите на **компьютере** в папку `tiktok-clipper/media/<папка источника>`,
   готовые клипы появляются в `tiktok-clipper/clips`.

**Вариант 2. Компьютер с Linux или Mac без Docker:** `bash install.sh --whisper`, затем
`CLIPPER_TOKEN=MoiParol2026 bash start.sh --lan`. Адрес для телефона программа напишет сама.

**Вариант 3. VPS с доменом (доступ из любого места):** впишите в `.env` ещё строку
`DOMAIN=clips.вашдомен.ru` (домен должен указывать на сервер) и запустите
`docker compose --profile https up -d --build`. Открывайте **`https://clips.вашдомен.ru`**.
Без https пароль передаётся открыто — на VPS используйте только этот вариант.

> **Про кнопку «Поделиться».** Отправить файл прямо в TikTok браузер разрешает только по адресу
> `127.0.0.1` (Android, вариант A1) или по `https` (вариант 3). По адресу вида `http://192.168.…`
> кнопка честно скажет, что недоступна, — тогда нажимайте **«Скачать»**, а потом выкладывайте
> видео в TikTok из галереи (iPhone: после скачивания нажмите «Поделиться» → «Сохранить видео»).

### A4. Проверка, что всё работает (тестовый клип)

1. Откройте программу. Внизу 5 вкладок: **Сегодня, Клип, Очередь, Клипы, Настройки**.
2. Откройте вкладку **«Настройки»** → карточка **«О системе»**: у ffmpeg, libass и H.264 должно быть
   зелёное «есть». В карточке **«Распознавание речи»** у whisper.cpp (телефон) или faster-whisper
   (компьютер) должно быть «установлен».
3. Откройте вкладку **«Клип»**. В списке **«Источник»** выберите **«Загруженные с телефона»**.
4. Нажмите **«Загрузить короткое видео с телефона»** и выберите любое короткое видео со звуком
   из галереи (до 15 минут).
5. Видео откроется на экране **«Выбор момента»**. Ничего не меняя, нажмите **«Сделать клип»**.
6. Откроется **«Очередь»**: полоска прогресса и надписи «Извлекаю звук», «Распознаю речь»,
   «Собираю видео». Дождитесь «Готово» и нажмите **«Открыть клип»**.
7. На экране **«Готовый клип»** нажмите ▶. Видео должно быть вертикальным, с субтитрами,
   если в нём была речь. Всё работает.

## Часть B. Первичная настройка

### B1. Добавить источник

Источник — это сериал, фильм, стример или блогер, из которого вы делаете клипы.

1. Вкладка **«Настройки»** → **«Добавить источник»**. Откроется экран **«Новый источник»**.
2. **«Название»** — например, «Во все тяжкие».
3. **«Тип»** — нажмите одну из кнопок: **Сериал, Фильм, Стрим, Блогер**.
4. **«Папка с видео»** — короткое имя латиницей, например `breaking_bad`. Программа создаст эту папку сама.
5. Для стримов и блогеров можно заполнить **«YouTube: ID канала (необязательно)»** — тогда на экране
   «Сегодня» будет ссылка на свежее видео. ID найдёте так: страница канала на YouTube → «Подробнее
   о канале» → «Поделиться каналом» → «Скопировать идентификатор канала» (начинается с `UC`).
6. Нажмите **«Сохранить источник»**.

### B2. Положить файлы в папку

Большие файлы (фильм на 2 ГБ) **не загружаются через браузер** — они просто лежат в папке.

* **Android (Termux):** откройте приложение «Файлы» → «Внутренняя память» → **TikTokClipper** →
  папка источника (например `breaking_bad`) и скопируйте туда видео. Точный путь к папке написан
  на экране «Выбор момента» под списком файлов: «Папка на устройстве с сервером: …».
* **Компьютер:** папка `tiktok-clipper/media/<папка источника>`.

Совет: если рядом с фильмом лежит файл субтитров **с тем же именем** (`film.mkv` и `film.srt`),
программа точнее предлагает моменты, а субтитры можно взять из него — без распознавания речи.

### B3. Рамка вебкамеры (для стримов и блогеров)

В клипе стрима сверху будет экран игры, а снизу — лицо стримера из вебкамеры. Программе нужно
показать, где в кадре вебкамера.

1. Сохраните источник с раскладкой **«Экран + вебкамера»** — сразу откроется экран **«Рамка вебкамеры»**.
   (Позже: «Настройки» → источник → кнопка **«Рамка вебкамеры (задана)»** или **«(не задана)»**.)
   Если пишет, что видео нет, — сначала положите файл в папку (шаг B2).
2. На кадре из видео есть жёлтая рамка **КАМЕРА**. Потяните её пальцем на окошко вебкамеры.
   Тяните за белые кружки в углах, чтобы рамка точно совпала с окошком.
3. Ползунок **«Кадр»** показывает другой момент видео, если на этом кадре вебкамеру не видно.
4. Ниже, в блоке **«Как будет в клипе»**, сразу видно результат: экран сверху, вебкамера снизу.
5. Нажмите **«Сохранить рамку»**.

Кнопка **«Найти лицо автоматически»** есть, только если на устройстве установлен OpenCV
(на компьютере с Docker — есть; в Termux — `bash ~/tiktok-clipper/install.sh --face`, но может
не установиться — тогда просто тяните рамку пальцем). Если вебкамеры у стримера нет — нажмите
**«Без вебкамеры»**: клипы будут в режиме «один кадр».

### B4. Профиль субтитров и раскладка

В карточке **«Профиль нарезки»** источника:
* **«Раскладка»**: **«Один кадр»** (фильм в центре на размытом фоне) или **«Экран + вебкамера»**.
* **«Увеличение кадра»** (для «Один кадр»): больше — фильм крупнее, края обрезаются.
* **«Экран сверху»** и **«Зона субтитров»** (для «Экран + вебкамера»): какую часть высоты занимает экран
  и полоса для субтитров; остальное — вебкамера.
* **«Зеркало по умолчанию»**, **«Субтитры по умолчанию»** — переключатели.
* **«Профиль субтитров»**: «Классика: белый, текущее слово жёлтое», «Неон: белый, текущее слово зелёное»
  или «Спокойный: без подсветки, по 2 слова».
* **«Язык речи»**: лучше выбрать язык явно (например, «Русский») — распознавание будет точнее.

Нажмите **«Сохранить источник»**.

### B5. Расписание

1. «Настройки» → карточка **«Расписание»**.
2. **«Дата старта»** — день первой публикации.
3. **«Интервал, дней»** — через сколько дней следующий пост (обычно 3: пн → чт → вс).
4. **«Постов в блоке»** — сколько постов подряд из одного источника (обычно 3).
5. **«Порядок типов»** — стрелками ↑ ↓ задайте, в каком порядке идут типы (например: сериал → фильм →
   стрим → блогер). После блока одного типа всегда идёт другой; источники одного типа идут по очереди.
6. Нажмите **«Сохранить расписание»**. На вкладке «Сегодня» появится план.

## Часть C. Каждый день

1. Откройте программу (значок **«Нарезка»**). Откроется **«Сегодня»**: что публиковать
   (например, «Во все тяжкие»), **«Пост 2 из 3 в блоке»**, дата и пометка «сегодня» или
   «просрочен на N дн.», а также **«Следующий файл»** — какой файл брать. Для стримов и блогеров —
   ссылка «Свежее на YouTube» с датой.
2. Нажмите **«Выбрать файл»**. Откроется экран **«Выбор момента»** со списком файлов источника.
   Рекомендуемый файл подсвечен и подписан «★ рекомендуем». Нажмите на нужный файл.
3. Найдите момент — двумя способами:
   * **«Предложить моменты»** → подождите (первый раз для длинного фильма — несколько минут, потом
     мгновенно) → появится список моментов с пометками «громко», «всплеск звука», «много речи».
     Нажмите на момент — ползунки встанут на него.
   * Или вручную: смотрите видео в плеере, ползунок **«Перемотка»**, затем **«Начало = позиция»** и
     **«Конец = позиция»**. Точная подстройка — кнопки **«−1 с» / «+1 с»** или ввод времени в поля
     **«Начало»** и **«Конец»** (вид `12:34.5`). Ползунки **«Начало»** и **«Конец»** под полями двигают
     границы. Проверить — **«▶ Проиграть отрезок»**. Внизу видно **«Длительность»**.
4. В карточке **«Настройки клипа»** проверьте переключатели **«Зеркало (отразить картинку)»** и
   **«Субтитры»**, при необходимости **«Язык речи»** и **«Стиль субтитров»**.
5. Для стримов: **«Раскладка»** = «Экран сверху + вебкамера снизу». Нажмите **«Проверить рамку
   вебкамеры»**: если стример передвинул окошко камеры — поправьте рамку и нажмите «Сохранить рамку».
6. Нажмите **«Сделать клип»**. Откроется **«Очередь»**.
7. Дождитесь «Готово». Экран можно выключить или закрыть браузер — работа не прервётся,
   при следующем открытии задача будет в «Очереди». Предупреждения (⚠) читайте — они объясняют,
   например, что речь не найдена.
8. Нажмите **«Открыть клип»** → экран **«Готовый клип»**. Посмотрите видео.
9. **Поправьте субтитры**, если нужно: в карточке **«Субтитры»** исправьте текст строки или время
   (начало и конец строки), лишнюю строку удалите крестиком ×, недостающую добавьте
   **«+ Добавить строку»**. Нажмите **«Пересобрать»** — клип соберётся заново за полминуты,
   речь заново не распознаётся.
10. Нажмите **«Поделиться»** и выберите **TikTok**. (Если кнопка недоступна — **«Скачать»**, и выкладывайте
    из галереи: клип уже лежит в папке **Movies/TikTokClips**.)
11. После публикации нажмите **«Опубликовано»** (здесь или на экране «Сегодня»). План сдвинется
    на следующий пост.

Если сегодня не получается — на «Сегодня» есть **«Перенести на завтра»** и **«Пропустить»**
(пост пропускается, следующий встаёт на эту дату). Случайно нажали — **«Отменить последнее действие»**.
Пропущенный день ничего не ломает: пост просто остаётся текущим с пометкой «просрочен».

## Часть D. Если что-то пошло не так

| Проблема | Причина | Что сделать |
|---|---|---|
| **В клипе нет звука** | В исходном файле нет звуковой дорожки (в «Очереди» будет ⚠ «В исходнике нет звука — добавлена тишина») | Возьмите другой файл. Если предупреждения нет — проверьте громкость телефона и что плеер не на «без звука» |
| | Телефон на беззвучном | Прибавьте громкость кнопками сбоку |
| **Субтитры с ошибками** | Модель tiny ошибается чаще | «Настройки» → «Распознавание речи» → «Модель»: base (телефон) или small (компьютер) → «Сохранить». На телефоне сначала скачайте модель: `bash ~/tiktok-clipper/install.sh --model base` |
| | Язык определился неверно | На «Выбор момента» выберите «Язык речи» явно, например «Русский» |
| | Отдельные слова | «Готовый клип» → исправьте строки → «Пересобрать» |
| **Субтитров нет вообще** | ⚠ «Распознавание речи не установлено» | Выполните `bash ~/tiktok-clipper/install.sh --whisper` (A1, шаг 9) |
| | ⚠ «Речь не найдена» | В отрезке только музыка или шум — это нормально. Можно вписать строки вручную («+ Добавить строку» → «Пересобрать») |
| **Клип не виден в галерее** | Android добавляет новые файлы в галерею не сразу | Откройте «Файлы» → Movies → TikTokClips — клип там. Чтобы галерея видела сразу: поставьте приложение **Termux:API** из F-Droid и выполните `pkg install termux-api` |
| **Кнопка «Поделиться» не работает** | Браузер разрешает отправку файлов только по `127.0.0.1` или `https` | Нажмите «Скачать» и выложите из галереи. Для компьютера/VPS — вариант 3 из A3 (https) |
| **Телефон засыпает, задача стоит или пропала** | Android усыпляет или закрывает Termux | Не смахивайте Termux из недавних приложений. «Настройки телефона» → «Приложения» → Termux → «Батарея» → **«Без ограничений»**. Программа сама не даёт телефону уснуть во время нарезки, а прерванная задача после перезапуска сервера начнётся заново (в «Очереди» будет ⚠ «запущена заново») |
| | В Termux появилось `[Process completed (signal 9)]` | Это Android 12+ закрыл Termux. Android 14+: «Настройки» → «Для разработчиков» → включите **«Отключить ограничения дочерних процессов»**. Затем запустите сервер снова (часть E) |
| **Сервер не открывается** («Не удаётся получить доступ к сайту») | Сервер не запущен (Termux закрыт или телефон перезагружался) | Запустите заново (часть E) |
| | Опечатка в адресе | Адрес ровно `127.0.0.1:8080` |
| | В Termux ошибка `Address already in use` | Сервер уже запущен в другом окне Termux. Пользуйтесь им или закройте Termux полностью и запустите снова |
| | Сервер на компьютере | Телефон в том же Wi-Fi? Компьютер включён? Адрес компьютера мог смениться — проверьте `ipconfig` снова. Брандмауэр Windows должен разрешить порт 8080 |
| | Сервер пишет «ОШИБКА: сервер не запущен… пароль не задан» | Задайте пароль CLIPPER_TOKEN (A3, шаг 3). Это защита, а не поломка |
| **Закончилось место** | Клипы и временные файлы | «Клипы» → откройте старый клип → «Удалить клип». Удалите старые фильмы из папок источников. Кэш программы можно удалить командой `rm -rf ~/tiktok-clipper/data/cache` — это безопасно |
| **«ffmpeg собран без libass»** при установке | Установлен чужой ffmpeg | Termux: `pkg install ffmpeg`. Компьютер: используйте Docker (A3) |
| **Видео не играет в плеере, вместо него кадры** | Браузер не умеет этот формат (AVI, HEVC и т.п.) | Ничего страшного: двигайте ползунок «Перемотка» — показываются кадры, клип сделается как обычно |

## Часть E. Запуск после перезагрузки телефона

После перезагрузки телефона сервер не работает, пока вы его не запустите:

1. Откройте **Termux**.
2. Наберите:
   ```
   clipper
   ```
   (или полностью: `bash ~/tiktok-clipper/start.sh`)
   *Что увидите:* «Сервер запущен. Откройте в браузере: http://127.0.0.1:8080».
3. Сверните Termux кнопкой «Домой» и откройте значок **«Нарезка»**.

**Автозапуск (по желанию):** установите из F-Droid приложение **Termux:Boot**, откройте его один раз,
затем выполните в Termux `bash ~/tiktok-clipper/install.sh --autostart`. После этого сервер будет
запускаться сам при включении телефона.

**Компьютер с Docker:** сервер запускается сам вместе с Docker Desktop. Если нет — в папке программы
выполните `docker compose up -d`.
